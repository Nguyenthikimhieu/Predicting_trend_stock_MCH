STOCK PRICE TREND FORECAST FOR MASAN CONSUMER CORPORATION (Q1 2024)

1. OBJECTIVES AND EXPECTED OUTCOMES

This study aims to forecast the stock price trend of Masan Consumer Corporation during the first three months of 2024 by collecting, analyzing, and modeling historical market data to deliver actionable insights for investors and corporate decision-makers. The research synthesizes modeling results to evaluate the forecasting model's accuracy, efficiency, and practical applicability in real-world trading strategies.

2. DATA SOURCE

Data is extracted using the vnstock Python library, comprising the following variables: time, open, high, low, close, volume, and ticker. By analyzing this dataset, the project aims to identify recurring patterns and trends in Masan's stock price fluctuations during the first three months of 2024. Applying statistical methods and predictive modeling enables the construction of an accurate forecasting model, giving investors a clearer understanding of the potential returns and risks associated with investing in Masan during this timeframe. The expected outcome is a comprehensive stock price trend and forecast report, delivering high-value analytical support for investment and strategic decision-making.

3. TOOLS AND TECHNIQUES

Programming Language: Python
Methodology: Predictive Modeling / Time-Series Analysis

4. IMPLEMENTATION WORKFLOW

To forecast the stock price trend of Masan Consumer Corporation for the first three months of 2024 using Python, the following steps are executed:

Data Collection: Retrieve reliable historical stock price data for Masan using Python libraries such as vnstock.

Data Preprocessing: Utilize pandas to clean, structure, and normalize the raw data files, ensuring data completeness and accuracy.

Data Analysis and Modeling: Apply data analysis techniques and statistical time-series modeling, such as the SARIMAX model, to forecast stock price trends.

Model Evaluation and Tuning: Assess forecasting performance using evaluation metrics like RMSE (Root Mean Square Error) and fine-tune model hyperparameters to optimize predictive accuracy.
